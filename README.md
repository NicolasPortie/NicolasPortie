Desenvolvo sistemas de negócio, APIs e integrações com C# e .NET. No frontend, trabalho com React e TypeScript em aplicações web e sites interativos.

## Áreas de atuação

- Arquitetura e evolução de sistemas, com modelagem de regras de negócio, persistência de dados e controle de acesso.
- Comunicação em tempo real com mensagens, presença de usuários e chamadas de áudio e vídeo.
- Automações com IA, bots para Telegram e WhatsApp e integrações de agentes via MCP.
- Interfaces web responsivas, dashboards e animações com GSAP.
- Integração com hardware, incluindo leitores RFID e comunicação serial.
